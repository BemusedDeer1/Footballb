# ⚽️ Football Hub Telegram Bot | ربات پیشرفته فوتبال هاب

ربات جامع تلگرامی فوتبالی و گیمینگ با رابط کاربری اختصاصی، سیستم رنکینگ ۱۲ سطحی، مینی‌گیم‌های تعاملی، پیش‌بینی مسابقات باشگاهی و ملی (فیفادی)، و جک‌پات کمبو ۵ مسابقه‌ای.

---

## 🚀 ویژگی‌های کلیدی (Key Features)

1. **🌍 مسابقات زنده و بین‌المللی (FIFA Day):**
   * پوشش لیگ‌های برتر اروپایی (لیگ جزیره، لالیگا، سری آ، بوندسلیگا، لوشامپیونه، چمپیونزلیگ)
   * پوشش کامل لیگ برتر خلیج فارس ایران
   * پوشش ویژه بازی‌های ملی در فیفادی، انتخابی جام جهانی آسیا و اروپا و لیگ ملت‌های اروپا
2. **🎰 جک‌پات کمبو ۵ مسابقه‌ای (Jackpot Combo):**
   * امکان ثبت فرم ۵تایی برای بازی‌های بزرگ هفته با استخر جایزه ۵۰۰ امتیازی
   * اهدای جوایز ویژه برای ۵ از ۵ صحیح و جوایز تسلیحاتی برای ۴ از ۴
3. **⚔️ مینی‌گیم‌های چندنفره و گروهی:**
   * دوئل اطلاعات عمومی ۱ به ۱ (`/duel`) با بانک بیش از ۸۰۰۰ سوال
   * بتل ۲ به ۲ تیمی (`/battle`) با سیستم لابی و همراهی دو هم‌تیمی
   * پنالتی تک‌ضرب مرگ ناگهانی (`/penalty`) با ایموجی تاس متحرک تلگرام
   * چالش اطلاعاتی حدس بازیکن (`/guess`) با بیش از ۶۰ ستاره معتبر و سرنخ‌های چندگانه
   * گردونه شانس وزنی (`/wheel`) و شوت روزانه (`/shoot`)
4. **👤 پروفایل لوکس و کارت بازیکن:**
   * سیستم سطح‌بندی (Leveling) و نوار پیشرفت XP یونیکد
   * ۱۲ رنک متنوع از Academy تا The G.O.A.T و Football Immortal
   * تالار افتخارات فصلی: ثبت دائمی رتبه‌های اول، دوم، سوم و چهارم در پایان هر سیزن ماهانه
   * امکان دریافت اطلاعات هر بازیکن با ریپلای کلمه **«اطلاعات»** یا **/info** روی پیام او
5. **🛡 امنیت و پایداری بالا:**
   * محافظت کامل دسترسی ادمین برای دستور حیاتی `/set_live` و `/reset_points`
   * جلوگیری کامل از فارم و خلق امتیاز کاذب در بازی‌های امتیازی با سیستم تسویه امن
   * وب‌سرور داخلی Health Check روی پورت 8080 جهت جلوگیری از Sleep شدن در هاست‌های ابری رایگان

## ⚙️ متغیرهای محیطی (Environment Variables)

یک فایل به نام `.env` در مسیر اصلی پروژه بسازید و مقادیر زیر را در آن قرار دهید:

```env
BOT_TOKEN=YOUR_TELEGRAM_BOT_TOKEN
ADMIN_ID=YOUR_NUMERIC_TELEGRAM_ID
DATABASE_PATH=football_hub.db
PORT=8080
```

## 📦 راه‌اندازی و اجرا (Installation & Run)

### روش ۱: اجرای مستقیم با پایتون

```bash
# نصب پیش‌نیازها
pip install -r requirements.txt

# اجرای ربات
python bot.py
```

### روش ۲: اجرا با داکر (Docker)

```bash
docker build -t football-hub-bot .
docker run -d --name football_bot --env-file .env -p 8080:8080 football-hub-bot
```

## 🎮 لیست دستورات (Bot Commands)

| دستور | عملکرد |
| :--- | :--- |
| `/start` | باز کردن منوی اصلی و داشبورد بازیکن |
| `/ranking` | مشاهده جدول رده‌بندی ۱۵ بازیکن برتر سیزن |
| `/duel` | شروع دوئل اطلاعات عمومی ۱ به ۱ (ریپلای روی حریف) |
| `/battle` یا `بتل` | شروع بتل ۲ به ۲ تیمی (ریپلای روی حریف) |
| `/penalty` یا `پنالتی` | شروع پنالتی تک‌ضرب (ریپلای روی حریف) |
| `/guess` یا `حدس` | شروع چالش ۳۰ ثانیه‌ای حدس ستاره فوتبال |
| `/jackpot` یا `جکپات` | ورود به بخش جک‌پات کمبو ۵ مسابقه‌ای |
| `/wheel` یا `گردونه` | چرخاندن گردونه شانس روزانه |
| `/shoot` یا `شوت` | شوت زدن روزانه با ایموجی متحرک تلگرام |
| `/daily` یا `جایزه` | دریافت پاداش ورود روزانه |
| `اطلاعات` یا `/info` | مشاهده کارت بازیکن (با ریپلای روی پیام شخص) |
| `/set_live` | تنظیم گروه اختصاصی مسابقات (فقط ادمین) |
| `/reset_points` | ریست دستی امتیازات به ۱۰۰ (فقط ادمین) |
| `/Ch_on` & `/Ch_off` | فعال/غیرفعال‌سازی حالت آزمایشی پاسخ‌ها (فقط ادمین در پیوی) |
